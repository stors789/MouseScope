## MouseScope v2.3.0 - Entry Robustness and TST Thresholding

MouseScope v2.3.0 focuses on reviewability and more stable behavior scoring. It improves Y-maze and Elevated Plus Maze arm-entry counting, adds entry-depth visualization for Y-maze videos, and expands Tail Suspension Test (TST) thresholding and quality-control outputs.

### Highlights

- Improved Y-maze arm-entry scoring so the same arm stays locked during shallow/deep boundary jitter or brief Unknown-region excursions.
- Added Y-maze entry-depth trigger-region overlay to annotated result videos.
- Improved Elevated Plus Maze arm-entry scoring with the same same-arm lock and stable-center reset logic.
- Added optional automatic TST behavior-threshold estimation and sensitivity control.
- Improved TST swing filtering so regular whole-body swing is less likely to be counted as struggling.
- Added TST detected-rate and uncertain-time QC fields.
- Added TST activity-curve and swing-aware ethogram outputs.
- Improved upload error handling for large files and insufficient disk space.
- Updated bilingual manuals and visible version labels to v2.3.0.

### Upgrade Notes

- Existing result files are not modified. Re-run analyses to get the updated entry counting, Y-maze entry-depth overlay, or TST threshold outputs.
- Y-maze and EPM now allow a same-arm re-entry only after a stable center return or entry into a different arm.
- TST automatic thresholds are optional; manual review of annotated videos remains recommended for formal statistics.

### Validation

- Python compile checks passed for updated modules.
- Route and short-analysis smoke checks passed.
- Manual encoding and bilingual language-switch checks passed.
- Packaged Windows desktop build was launched and verified through the local web interface.

## MouseScope v2.3.0 - 入臂容错与 TST 自动阈值

MouseScope v2.3.0 重点提升结果复核体验和行为判定稳定性。本版本改进了 Y 迷宫和高架十字迷宫的入臂计数，给 Y 迷宫结果视频新增入臂深度区域可视化，并扩展了悬尾实验的自动阈值与质控输出。

### 主要更新

- 改进 Y 迷宫入臂判定：同一臂内浅区/深区边界抖动或短暂进入 Unknown 区域时，不再重复计入臂。
- Y 迷宫结果视频新增入臂深度触发区叠加显示，便于人工复核。
- 高架十字迷宫新增同款入臂容错：同一臂保持锁定，稳定回中心或进入另一臂后才允许再次计数。
- 悬尾实验新增可选自动行为阈值估计和阈值灵敏度控制。
- 优化悬尾摆动过滤，降低规则整体摆动被误判为挣扎的概率。
- 悬尾结果新增检测率和不确定时间等质控字段。
- 悬尾新增活动曲线和区分摆动的 ethogram 输出。
- 改进大文件上传、磁盘空间不足等错误提示。
- 更新中英双语手册和界面可见版本号为 v2.3.0。

### 升级说明

- 已有结果文件不会被自动修改。需要重新分析后，才能得到新的入臂计数、Y 迷宫入臂深度叠加和 TST 阈值输出。
- Y 迷宫和 EPM 中，同一臂再次计数需要先稳定回到中心区，或进入另一条臂。
- TST 自动阈值是可选功能；正式统计前仍建议复核标注视频。

- 已通过路由 smoke 和短分析 smoke 检查。
- 已通过手册编码和中英文切换检查。
- 已打包 Windows 桌面版，并通过本地 Web 界面启动验证。

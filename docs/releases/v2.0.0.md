## MouseScope v2.0.0 - Unified Workbench, EPM & Y-Maze Update

MouseScope v2.0.0 is planned as a major release that adds two new behavior-analysis modules on top of the existing TST, OFT, and NOR workflow, while also rebuilding the UI and batch-processing experience around a unified workbench:

- Elevated Plus Maze (EPM)
- Y-Maze spontaneous alternation

### 中文更新摘要

- 新增高架十字迷宫模块
  - 通过手动画出的中心区、两条开放臂和两条封闭臂进行判区
  - 输出开放臂、封闭臂、中心区停留时间
  - 输出开放臂进入次数、封闭臂进入次数、开放入臂百分比、首次开放臂潜伏期
  - 支持逐帧轨迹、分箱统计、热图、轨迹图和标注视频

- 新增 Y 迷宫模块
  - 通过手动画出的中心区和 Arm A/B/C 进行判区
  - 输出各臂停留时间、总入臂数、交替次数、交替率
  - 记录逐帧区域序列与最近三次入臂序列
  - 支持逐帧轨迹、分箱统计、热图、轨迹图和标注视频

- GUI 与流程更新
  - 上传页新增 EPM / Y 迷宫入口
  - 手册页新增 EPM / Y 迷宫模块说明
  - 多视频上传后先进入批量工作台，再逐视频进入独立配置页
  - 标定页支持按视频分别保存 ROI、时间窗、检测参数与过程态草稿
  - 监控页支持新模块的实时指标展示与结果下载
  - EPM / Y 迷宫补齐可选检测遮罩配置，与 OFT / NOR 交互模型统一

- 开发与维护
  - 新增 `v2.0.0` 模块计划文档：`docs/plans/v2.0.0_epm_ymaze_plan.md`
  - 新增 `v2.0.0` UI 与架构重构计划：`docs/plans/v2.0.0_ui_unification_refactor_plan.md`
  - 新增系统设计文档：`docs/system_design.md`
  - 新增批量草稿会话存储与磁盘快照机制：`services/session_store.py`
  - 新增实验注册表与批次完整性校验：`services/experiment_registry.py`
  - 新增统一分析配置构建层：`services/analysis_builders.py`
  - 新增最小页面 / 路由 / inline JS smoke 检查：`tools/smoke_routes_v2.py`
  - 新增 5 个实验模块的短程端到端 smoke：`tools/smoke_short_analyses_v2.py`
  - 修复 `generate_video` 在公共配置合并时被默认值覆盖的问题
  - 目标是在保留原有 TST / OFT / NOR 分析能力的前提下，完成工作台、批量流转和工程结构的统一重构

### English Summary

- Added a full Elevated Plus Maze module
  - Manual center/open/closed zone definition for each EPM ROI
  - Open-arm, closed-arm, and center occupancy metrics
  - Open/closed entries, open-entry percentage, and first open-arm latency
  - Frame-level tracking, time bins, heatmaps, trackmaps, and annotated video

- Added a full Y-Maze module
  - Manual center + Arm A/B/C definition for each Y-maze ROI
  - Per-arm occupancy, total arm entries, alternation count, and alternation percentage
  - Frame-level zone trace plus recent arm-entry sequence logging
  - Time bins, heatmaps, trackmaps, and annotated video outputs

- GUI additions
  - New EPM / Y-Maze experiment entries on the upload page
  - New manuals for both modules
  - New calibration and live-monitor pages for both assays
  - A redesigned batch workflow centered on a dedicated batch workspace
  - Draft persistence for per-video setup state and crash-resistant session snapshots
  - Optional detection-mask editing for EPM and Y-Maze to match OFT / NOR behavior
  - A broader UI and architecture refactor targeting a unified workbench experience

### Notes

- This release keeps the existing TST, OFT, and NOR modules intact.
- The v2.0.0 target also includes a larger UI, batch-workflow, and application-structure refactor beyond the new maze modules.

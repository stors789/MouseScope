## 🎉 MouseScope v2.0.0 - 平台化重构与新迷宫模块更新

MouseScope 迎来一次真正意义上的大版本升级。  
本版本在保留原有 **悬尾实验（TST）**、**旷场实验（OFT）** 和 **新奇物体识别（NOR）** 三大模块的基础上，新增了 **高架十字迷宫（EPM）** 与 **Y 迷宫（Y-Maze）**，并把整个软件重构为一套更完整、更统一、更适合长期使用的行为学视频分析工作台。

这次更新不只是“多了两个实验模块”。  
它同时重做了 **批量处理流程、ROI 与迷宫配置逻辑、检测遮掩框交互、热图/轨迹图生成方式、手册结构、TXT 报告字段、首页与上传页展示方式，以及内部代码结构**。  
我们希望 MouseScope 不只是能跑出结果，而是能更稳定地服务真实实验室里的多视频、多条件、多人协作场景。

#### 本次版本重点

- 新增 **高架十字迷宫 EPM** 模块
- 新增 **Y 迷宫 Y-Maze** 模块
- 批量模式升级为 **每个视频独立配置的批量工作台**
- 统一了 5 个实验模块的 **配置逻辑与界面布局**
- 统一了 **ROI / 时间窗 / 检测遮掩框 / 参数预览** 交互
- 迷宫模块改为 **标准模板热图与轨迹图**
- 使用手册补充为更完整的 **中英双语版本**
- 新增 **系统设计文档** 与基础 smoke tests，便于后续维护

#### 本次更新内容

- 新增 EPM 分析能力
  - 采用 **中心区 + 2 条开放臂 + 2 条封闭臂** 的全手动画区方式
  - 输出开放臂、封闭臂、中心区时间
  - 输出开放臂时间占比、开放臂进入次数、封闭臂进入次数、开放臂进入占比
  - 输出首次进入开放臂潜伏期、总路程、速度以及时序统计

- 新增 Y 迷宫分析能力
  - 采用 **三角形中心区 + Arm A / B / C** 的真实实验几何
  - 输出各臂停留时间、各臂进入次数、总入臂数
  - 输出交替次数、交替机会数、交替率与入臂序列
  - 支持逐帧轨迹、分箱统计、热图与轨迹图

- 批量工作流重构
  - 多视频上传后不再直接在 ROI 页面切换视频
  - 改为先进入 **批量工作台**，每个视频单独配置
  - 每个视频可独立保存 ROI、时间窗、遮掩框与参数
  - 配置完成后再统一启动批量分析，逻辑更清晰，也更适合实验室交接

- 统一界面与交互
  - 统一上传页、配置页、监控页和手册页的视觉风格
  - 统一各模块的 ROI 卡片、时间窗、参数与提示逻辑
  - 检测遮掩框支持 **闭合多边形** 绘制，末尾点可吸附回首点
  - 首页、上传页和手册文案改为更适合最终使用者而非开发者视角

- 迷宫图像输出升级
  - EPM 与 Y-Maze 的热图和轨迹图不再直接跟随手画 ROI 形状
  - 改为映射到 **标准十字迷宫** 与 **标准 Y 迷宫模板**
  - 更适合不同视频之间做直观比较与汇报展示

- 结果与文档更新
  - TXT 报告字段统一为 **中文（English）** 双语标签
  - EPM / Y-Maze 使用手册补齐为完整章节，加入导航栏、参数说明与结果字段解释
  - README 重写为更适合 GitHub 首页展示的中文优先版本
  - 增加系统设计文档，明确后续扩展的统一结构

- 代码结构与稳定性
  - 拆出 `services/experiment_registry.py`、`services/analysis_builders.py`、`services/session_store.py`
  - 为多模块分发、批量配置和会话恢复建立统一骨架
  - 新增 `tools/smoke_routes_v2.py` 与 `tools/smoke_short_analyses_v2.py`
  - 降低未来继续新增实验模块时把 `app.py` 越改越长、越改越乱的风险

#### 项目目标

MouseScope 的目标不是做一个“参数很多但没人敢用”的工具，  
而是尽量把行为学实验中重复、耗时、容易出错的视频后处理流程，整理成一套更直观、更稳定、更容易交接的桌面工作流。

希望这个版本能帮助做 **TST / OFT / NOR / EPM / Y-Maze / 小鼠行为学视频分析** 的同学和研究人员减少重复劳动，提高分析效率，并降低批量处理中因为配置混乱带来的风险。

## MouseScope v2.0.0 - Platform Refactor & New Maze Modules

MouseScope receives a major platform-level update in this release.  
While keeping the existing **Tail Suspension Test (TST)**, **Open Field Test (OFT)**, and **Novel Object Recognition (NOR)** modules, version `v2.0.0` adds **Elevated Plus Maze (EPM)** and **Y-Maze**, and rebuilds the application into a more unified behavioral-analysis workbench.

This is not just a feature add-on.  
The update also reworks the **batch workflow, ROI and maze setup logic, detection-mask interaction, heatmap and trackmap rendering, manuals, TXT reports, top-level UI presentation, and internal application structure**.

#### What's new in this release

- Added full **Elevated Plus Maze (EPM)** support
- Added full **Y-Maze spontaneous alternation** support
- Rebuilt multi-video handling into a **batch workspace with per-video configuration**
- Unified **ROI / time-window / detection-mask / preview** logic across the 5 assays
- Upgraded maze heatmaps and trackmaps to **standard template rendering**
- Expanded the bilingual manuals and result labels
- Added a **system design document** and smoke-test coverage for future maintenance

#### Key changes

- EPM now uses fully manual five-zone drawing:
  - center zone
  - two open arms
  - two closed arms
  - Outputs include occupancy, entries, open-entry ratio, latency, distance, and speed

- Y-Maze now follows real assay geometry:
  - triangular center
  - Arm A / B / C
  - Outputs include arm occupancy, arm entries, total entries, alternation count, opportunities, rate, and entry sequence

- Batch workflow redesign:
  - Multi-video sessions no longer force users to switch videos inside one ROI page
  - Users now enter a dedicated batch workspace first
  - Each video keeps its own ROI, timing, mask, and parameter setup
  - Analysis starts only after every video card is complete

- Output and visualization upgrades:
  - TXT reports now use bilingual labels in the form of `中文 (English)`
  - EPM and Y-Maze spatial plots are rendered onto standard maze templates rather than raw skewed ROI shapes
  - Manuals were expanded into more complete bilingual guides with navigation and metric explanations

- Structural improvements:
  - Introduced shared services for experiment registration, analysis config building, and session persistence
  - Added smoke tests for routes and short end-to-end analysis runs
  - Reduced future maintenance risk as the project grows beyond a single monolithic entry file

#### Project vision

MouseScope is meant to be a practical desktop workflow for behavioral video analysis, not a script pile or a black-box demo.  
The goal is to make routine mouse-behavior analysis more reliable, easier to hand over, and easier to review in real lab use.

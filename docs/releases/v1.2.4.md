## 🎉 MouseScope v1.2.4 - Workflow & Reliability Update

MouseScope 迎来一次重要更新。  
本版本在保留原有 **悬尾实验（TST）**、**旷场实验（OFT）** 和 **新物体识别（NOR）** 三大分析模块的基础上，重点优化了批量处理流程、参数配置方式、结果导出结构以及使用手册内容。

这次更新更关注“真正每天会遇到的问题”。  
我们希望 MouseScope 不只是能跑出结果，而是能在多视频、多条件、长期使用的场景下更稳定、更清晰、更适合直接交付给实验人员使用。

#### 本次更新内容
- 批量模式升级为 **每个视频独立配置**
- TST / OFT / NOR 均支持为每个视频分别保存 **标定、ROI、时间窗和参数**
- 批量分析前新增更严格的 **配置完整性检查**
- 修复多视频场景下 **帧数、FPS、时间窗参考信息** 可能沿用首个视频的问题
- 批量结果输出改为在总输出目录下自动创建 **每视频独立子文件夹**
- ZIP 下载保留 **按视频分目录** 的结构，结果整理更清晰
- 默认启动方式调整为 **仅本机访问**，减少误暴露到局域网的风险
- 许可确认改为 **后端强制校验**
- 增加 **会话与缓存清理机制**，提升长期运行稳定性
- 重写并补充 **中英双语使用手册**
- 手册新增 **参数说明、结果字段解释、批量处理说明、排错建议与免责声明**
- 持续保持 **下载安装即可使用、0 代码需求、桌面 GUI 操作**

#### 项目目标
MouseScope 的目标不是做一个“参数很多但没人敢用”的工具，  
而是尽量把行为学实验中繁琐、重复、耗时间的视频后处理流程整理成一个更可靠、更直观、更容易交接的桌面工作流。

希望这个版本能帮助做 **TST / OFT / NOR / 小鼠行为学视频分析** 的同学和研究人员减少重复劳动，提高分析效率，同时降低批量处理中因为配置混乱带来的风险。

MouseScope receives a major workflow and reliability update in this release.  
While keeping the existing **Tail Suspension Test (TST)**, **Open Field Test (OFT)**, and **Novel Object Recognition (NOR)** modules, this version focuses on improving batch analysis, per-video configuration, result organization, and the user manual.

This update is centered on practical day-to-day usability.  
The goal is not only to produce results, but to make MouseScope more stable, clearer, and easier to hand over in real multi-video experimental workflows.

#### What's new in this release
- Batch workflow upgraded to **per-video independent configuration**
- **TST / OFT / NOR** now support saving **calibration, ROI, time windows, and parameters** separately for each video
- Added stricter **pre-run validation** before batch analysis starts
- Fixed multi-video issues where **frame count, FPS, and time window references** could incorrectly follow the first video
- Batch outputs now create **one subfolder per video** inside the selected output directory
- ZIP downloads now preserve the **per-video folder structure** for cleaner result organization
- Default startup is now **localhost only**, reducing the risk of accidental LAN exposure
- License confirmation is now **enforced on the backend**
- Added **session and cache cleanup**, improving long-running stability
- Reworked the **bilingual Chinese/English manuals**
- Manuals now include **parameter explanations, result field definitions, batch workflow guidance, troubleshooting tips, and disclaimers**
- Still designed as a **desktop GUI application with zero coding required**

#### Project vision
The goal of MouseScope is not to be a tool with many parameters that few people feel comfortable using,  
but to turn repetitive and time-consuming behavioral video analysis into a more reliable, more intuitive, and easier-to-transfer desktop workflow.

I hope this release can help students and researchers working on **TST / OFT / NOR / mouse behavioral analysis** reduce manual workload, improve efficiency, and lower the risk of configuration mistakes during batch processing.

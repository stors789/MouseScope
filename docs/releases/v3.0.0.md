## MouseScope v3.0.0 - Project Workspace and Workflow Refresh

MouseScope v3.0.0 introduces the Project Workspace as the main workflow for formal experiments. Projects can now organize groups, animals, videos, and analysis results in one place, while Quick Analysis keeps the original lightweight path for one-off video processing.

### Highlights

- Added project-oriented experiment management with project, group, animal, video, and result records.
- Added project APIs, project pages, and project home interactions for browsing and managing study data.
- Added reusable video frame reading/export helpers for result review and workflow integration.
- Refreshed the README, cover image, build metadata, and citation metadata for v3.0.0.
- Added calibration workbench and guided-tour assets to improve setup and onboarding.
- Fixed bilingual result labels so Tail Suspension Test TXT reports consistently use Chinese labels with English names in parentheses.

### Verification

- Added unit coverage for the project store.
- Rechecked Python syntax for updated core, route, service, and test modules.

## MouseScope v3.0.0 - 项目工作台与流程更新

MouseScope v3.0.0 新增“项目工作台”作为正式实验的主流程。用户可以围绕项目、组别、小鼠、视频和分析结果组织实验数据，同时保留“快速分析”入口，用于延续原有的轻量单次视频分析流程。

### 主要更新

- 新增以项目为中心的实验管理能力，支持项目、组别、小鼠、视频和结果记录。
- 新增项目 API、项目页面和项目首页交互，用于浏览和管理研究数据。
- 新增可复用的视频帧读取与导出辅助模块，服务于结果复核和流程集成。
- 更新 README、封面图、构建元数据和引用元数据到 v3.0.0。
- 新增标定工作台和引导游览相关资源，改善配置与上手体验。
- 修复结果 TXT 的双语字段命名，悬尾实验报告统一为“中文（English）”格式。

### 验证

- 新增项目存储单元测试。
- 重新检查 core、routes、services 和 tests 下 Python 文件语法。

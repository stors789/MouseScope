## MouseScope v2.2.0 - Forced Swim Test Module

MouseScope v2.2.0 adds a complete Forced Swim Test (FST) workflow to the existing desktop workbench. The release expands the platform from five to six supported assays and focuses on side-view multi-cylinder analysis, diameter-based calibration, automatic immobility thresholding, and review-friendly temporal QC outputs.

### Highlights

- Added the Forced Swim Test (FST) assay module.
- Supported side-view videos with one or more cylinders in the same frame.
- Added per-cylinder ROI setup, cylinder inner-diameter calibration, optional waterline reference, and optional detection masks.
- Added FST time-window modes: global, relative to first stable detection, and precise absolute video time.
- Added automatic per-ROI immobility threshold estimation from the video motion-score distribution.
- Added FST frame-level track CSV, summary CSV, temporal bins CSV, TXT report, ethogram, activity curve, and optional annotated video.
- Added complete bilingual FST manual content and bilingual UI strings.
- Updated FST annotated videos so animal contours, bounding boxes, centroids, and status labels carry behavior-state colors, while ROI boundaries remain neutral.
- Improved FST progress reporting during threshold estimation, scoring, and final annotated-video rendering.

### Upgrade Notes

- Existing result files are not moved or modified.
- Old FST result videos generated during pre-release testing should be regenerated if you need the corrected final-state overlay.
- FST temporal bin duration only affects `*_bins.csv` and temporal QC; it does not change the core immobility scoring in `*_summary.csv`.
- Historical v2.1.0 task records remain compatible with the Task Center.

### Validation

- Python compile checks passed for the updated backend and FST core modules.
- Route smoke checks passed for the main web workflow.
- Short analysis smoke checks passed for all supported assay workflows, including FST.
- FST-specific checks covered final-state annotated-video rendering, progress reporting, and visual color semantics.

## MouseScope v2.2.0 - 强迫游泳实验模块

MouseScope v2.2.0 新增强迫游泳实验（FST）完整流程。这个版本把平台支持的实验模块从五类扩展到六类，重点补齐侧视多圆筒分析、圆筒直径标定、自动不动阈值，以及便于复核的时间动态质控输出。

### 主要更新

- 新增强迫游泳实验 FST 模块。
- 支持侧视视频中单圆筒或同屏多圆筒分析。
- 新增按圆筒独立绘制 ROI、圆筒内径线标定、可选水线参考和可选检测遮罩。
- 新增 FST 三种时间窗：跟随全局、相对首次稳定检测、精确视频绝对时间。
- 新增按 ROI 自动估计不动阈值，阈值来自当前视频的运动评分分布。
- 新增 FST 逐帧 track CSV、summary CSV、时间分箱 CSV、TXT 报告、ethogram、活动曲线和可选标注视频。
- 新增完整中英双语 FST 使用手册与界面文案。
- 调整 FST 标注视频可视化：小鼠轮廓、外接框、质心和状态标签跟随行为状态变色，ROI 边界保持中性颜色。
- 改进 FST 阈值预扫描、正式评分和最终视频渲染阶段的进度显示。

### 升级说明

- 现有结果文件不会被移动或修改。
- 预发布测试期间生成的旧 FST 结果视频如果需要正确最终状态叠加，建议重新分析生成。
- FST 分箱时长只影响 `*_bins.csv` 和时间动态复核，不改变 `*_summary.csv` 的核心不动统计。
- v2.1.0 的历史任务记录仍可在任务中心中兼容查看。

### 验证

- 已通过更新后后端模块与 FST 核心模块的 Python 编译检查。
- 已通过主要 Web 流程路由 smoke 检查。
- 已通过所有支持实验模块的短分析 smoke 检查，其中包括 FST。
- 已针对 FST 最终状态结果视频渲染、进度显示和可视化颜色语义做专项检查。

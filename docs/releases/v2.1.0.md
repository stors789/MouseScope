## MouseScope v2.1.0 - Task Center and Backend Split

MouseScope v2.1.0 focuses on day-to-day usability after analyses are launched. The release keeps the existing five assay modules while making long-running jobs easier to find, revisit, download, and clean up.

### Highlights

- Added a Task Center for active analyses and local history.
- Persisted completed, stopped, failed, and interrupted run records in a local SQLite history database.
- Preserved result-folder visibility after restarting the app, including inference from result files for older records.
- Added record deletion from the Task Center without deleting result files.
- Split the large Flask entry file into page routes, API routes, preview services, analysis sessions, and payload geometry helpers.
- Updated packaging hidden imports so the refactored modules are included in desktop builds.

### Upgrade Notes

- Existing result files are not moved or modified.
- Task history is stored under `data/history/analysis_history.sqlite`.
- Records that were still marked as running before an app restart are shown as interrupted.

### Validation

- Python compile checks passed for the refactored backend modules.
- Route smoke checks passed for the main web workflow.
- Short analysis smoke checks passed for the supported assay workflows.
- Task Center API checks covered summary counts, history persistence, result-folder recovery, and non-running record deletion.

## MouseScope v2.1.0 - 任务中心与后端拆分

MouseScope v2.1.0 重点改善分析启动后的实际使用体验。在保留现有五个实验模块的基础上，本版本让长时间运行的任务更容易查找、回看、下载和清理。

### 主要更新

- 新增任务中心，用于集中查看运行中分析和本地历史记录。
- 使用本地 SQLite 历史库保存已完成、已停止、出错和已中断的任务。
- 软件重启后仍能看到结果目录，并可从旧记录的结果文件反推出目录。
- 新增任务中心记录删除功能，默认只删除记录，不删除真实结果文件。
- 将原本庞大的 Flask 入口拆分为页面路由、API 路由、预览服务、分析会话和 payload 几何处理模块。
- 更新打包 hidden imports，保证桌面版构建包含拆分后的新模块。

### 升级说明

- 现有结果文件不会被移动或修改。
- 任务历史存放在 `data/history/analysis_history.sqlite`。
- 软件重启前仍处于运行状态的任务，会在下次启动时显示为已中断。

### 验证

- 已通过后端模块 Python 编译检查。
- 已通过主要 Web 流程路由 smoke 检查。
- 已通过支持实验模块的短分析 smoke 检查。
- 已针对任务中心摘要计数、历史持久化、结果目录恢复和非运行记录删除做验证。

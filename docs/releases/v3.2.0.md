🎉 **MouseScope v3.2.0 - Light-Dark Box and Safer LDB Metrics**

MouseScope `v3.2.0` adds the **Light-Dark Box (LDB)** workflow as a formal public module.

The new LDB module is designed around two common recording conditions:

- **Visible dark chamber mode**: use this when the mouse can be detected reliably in both the light and dark chambers. MouseScope exports core LDB metrics, frame-level tracking, rectified trackmaps, heatmaps, and auxiliary locomotion/QC fields.
- **Invisible dark chamber mode**: use this when the dark chamber is opaque or the mouse cannot be detected reliably inside it. MouseScope infers light/dark occupancy from whether the mouse is visible in the light chamber and intentionally suppresses unreliable trajectory, heatmap, speed, and distance outputs.

LDB supports manual light/dark ROI drawing, optional doorway ignore zones, independent light/dark chamber dimensions, shared-edge length, transition dwell debounce, first-light latency, chamber entries, transitions, and binned output.

The doorway is now treated as an optional ignore band rather than a required scoring zone.
It helps when a dark door seam is falsely detected as the mouse, and in invisible-dark mode it prevents doorway-only head peeks from being counted as premature light entries.

The default Tail Suspension Test behavior has been switched back to the original stable algorithm path, while the newer LIS path remains available for comparison and future testing.

🎉 **MouseScope v3.2.0 - 明暗箱与可信 LDB 指标**

MouseScope `v3.2.0` 将 **明暗箱 Light-Dark Box (LDB)** 作为正式公开模块加入主流程。

新的 LDB 模块按两类常见视频条件设计：

- **暗箱可见模式**：当小鼠在明箱和暗箱内都能稳定检测时使用。MouseScope 会导出核心 LDB 指标、逐帧轨迹、规整轨迹图、热图和辅助运动学/QC 字段。
- **暗箱不可见模式**：当暗箱不透明，或暗箱内小鼠无法可靠检测时使用。MouseScope 会根据“小鼠是否出现在明箱”推断明/暗箱停留时间，并主动关闭不可信的轨迹、热图、速度和距离输出。

LDB 支持手动画明箱/暗箱 ROI、可选门区忽略带、明箱/暗箱独立尺寸、两箱公共边重合长度、转换稳定时间防抖、首次入明箱潜伏期、进入次数、转换次数和分箱输出。

门区现在更接近可选的忽略带，而不是必须统计的得分区。
它适合处理门缝黑线误检，也能在暗箱不可见模式下降低“只探头到门口就被算入明箱”的抖动。

悬尾实验的默认行为已切回原本稳定算法路径，新的 LIS 路径仍保留用于对比和后续测试。

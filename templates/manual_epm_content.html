高架十字迷宫完整操作手册

本手册覆盖实验逻辑、采集要求、5 区手动画区、检测遮罩、时间窗、主要参数，以及 EPM 结果字段的解释方式。

5 区手动画区 开放臂 / 封闭臂时间 入臂深度判定 检测遮罩可选 track / summary / bins

主要统计什么

分别统计开放臂、封闭臂和中心区时间，并输出开放臂时间比例、开放臂进入比例、潜伏期、距离和速度。

为什么改成手动画区

每个 ROI 都显式画出中心区、两条开放臂和两条封闭臂，避免自动推导整套迷宫带来的边界偏差。

为什么有入臂深度

只有质心进入臂区更深的位置才记为入臂，可减少臂口附近反复试探造成的重复计数。

1总览

EPM 模块用于分析小鼠在开放臂、封闭臂和中心区之间的空间偏好。最关键的是把迷宫边界画准，再用预览确认区域切换和入臂计数稳定。

  • 开放臂时间比例和开放臂进入比例通常要和总入臂数、总距离一起解释，避免把低活动视频误读成高焦虑。
  • 中心区单独统计，不会被并入开放臂或封闭臂，因此更容易发现长时间停留中心的视频。
  • 一个视频里如果有多个迷宫，每个 ROI 都会独立输出自己的结果表和热图。

注意两个开放臂时间比例

MouseScope 同时输出 open_time_percent_total 和 open_time_percent_arms_only。前者以总统计时长为分母，后者只以开放臂和封闭臂总时长为分母。

2采集要求

EPM 对边界清晰度和俯视稳定性比较敏感。边界越完整，后面的区域判定越可靠。

机位与视角

  • 优先使用稳定俯视或接近俯视的固定机位，不要在录制中移动或变焦。
  • 中心区和四条臂都应完整可见，尽量不要让臂端或交叉区被裁切。

背景与干扰

  • 保持鼠体与迷宫地面有明显亮度对比，减少阴影、反光和护栏高亮。
  • 开放臂外侧如果有亮背景或实验台边缘，建议优先使用检测遮罩。

不要用缩小统计区来掩盖误检

如果开放臂外侧背景容易被误检，更推荐加检测遮罩，而不是把开放臂区域硬缩小。

3上传与时间范围

上传页定义默认统计时间、FPS 覆盖和输出目录。ROI 设为“跟随全局”时，会直接沿用这里的时间窗口。

  • 如果只想分析视频中的一段，可先在上传页设置全局开始和结束时间。
  • FPS 元数据不可靠时建议手动覆盖，否则速度、距离和潜伏期可能受影响。
  • 多视频模式下会先进入批次页面，再逐条完成每个视频的 EPM 设置。

45 区画区与时间窗

每个 ROI 对应一个完整迷宫，只有中心区、开放臂 1/2、封闭臂 1/2 全部完成后，才会进入预览和正式分析。

5 区手动画区

  • 每个区域都用 4 个角点绘制，系统会自动归一化点序，所以关键是边界位置是否准确。
  • 中心区建议贴合十字交叉部分的真实范围；各臂建议按实际可活动区域绘制。

真实尺寸与厘米换算

  • 请填写中心区边长、开放臂长度和封闭臂长度，系统会据此估算 cm_per_px_est。
  • 这个尺度会影响距离、速度和运动阈值。

检测遮罩 detection mask

  • 遮罩只限制允许检测前景的区域，不会改变开放臂、封闭臂和中心区的统计边界。
  • 如果不单独绘制，系统默认使用 5 个手画区域的并集作为检测区域。
ROI 时间窗模式
模式含义推荐场景
global跟随上传页的全局开始 / 结束时间。大多数标准 EPM 分析。
precise按视频绝对时间指定开始 / 结束秒数。只分析固定片段，例如前 300 s。

完整 ROI 才会被统计

如果某个 ROI 只有部分区域完成，系统不会把它纳入预览或正式分析。

5参数字典

EPM 参数可以分为检测参数和行为统计参数两类。

检测参数
参数作用常见调法
bg_type指定背景偏浅还是偏深，决定前景分割方向。深色鼠配浅背景选 light；浅色鼠配深背景选 dark。
gray_threshold控制前景分割的严格程度。噪点多就提高；轮廓断裂或漏检就降低。
erosion_kernel / erosion_iter去掉碎点和毛边。边缘噪点多时增大；鼠体被过度侵蚀时减小。
dilation_kernel / dilation_iter修补断裂轮廓。轮廓碎裂时增大；背景粘进鼠体时减小。
min_area过滤过小误检轮廓。小亮点误检多就提高；小鼠体被漏掉就降低。
行为统计参数
参数作用结果影响
entry_depth_ratio定义质心需要深入臂区多远才记为一次入臂。直接影响 open_entries、closed_entries 和 open_entry_percent。
movement_threshold_cm_s区分移动与低活动 / 静止。影响 moving_time_s 和 immobility_time_s。
bin_seconds时间分箱长度。决定 *_bins.csv 每一行覆盖的时长。
generate_video是否导出带标注结果视频。关闭可提速，但会失去最直观的复核材料。

6结果字典

EPM 会导出结果视频、逐帧轨迹 CSV、summary CSV、分箱 CSV，以及每个 ROI 的热图和轨迹图。

*_analyzed.mp4

叠加手画区域、当前区域标签、入臂事件和轨迹的结果视频。

*_track.csv

逐帧记录区域、速度、累计距离和入臂事件。

*_summary.csv / *_bins.csv

输出核心统计结果和固定时间箱汇总。

*_track.csv
字段含义解读建议
frame原视频帧号。可用于回定位到结果视频。
time_s / window_time_s视频绝对时间与统计窗内相对时间。适合做时序分析。
zone / zone_group当前所在区域及其分组。zone_group 常见值为 open、closed、center。
arm_entry_event / arm_entry_name是否触发入臂以及对应臂名。建议结合结果视频一起复核。
*_summary.csv
字段含义解读建议
open_time_s / closed_time_s / center_time_s各区域总停留时间。建议和总活动量一起解释。
open_time_percent_total开放臂时间占总统计时长的百分比。最常用的开放臂时间指标。
open_time_percent_arms_only开放臂时间占开放 + 封闭臂总时长的百分比。适合排除中心区停留影响后再比较。

first_open_entry_latency_s首次进入开放臂潜伏期。若始终未进入开放臂，可能为空。

7批量流程

EPM 的批量模式是“每个视频各自配置，再统一运行”。不要只画第一个视频就直接开始整批分析。

  1. 上传多个 EPM 视频，并设置全局时间窗、FPS 覆盖和输出目录。
  2. 逐条打开视频卡片，完成当前视频的 5 区画区、检测遮罩、时间窗和参数设置。
  3. 保存当前设置并返回批次页面，再继续处理下一条视频。
  4. 确认所有卡片都显示为已完成后，再统一开始批量分析。

8常见问题与排错

  • 开放臂时间异常高：检查开放臂是否画得过宽，或外侧亮背景是否漏进了检测区域。
  • 开放臂时间异常低：检查开放臂是否画得过窄，或边缘阴影是否把鼠体切断了。
  • 入臂数明显偏高：优先提高 entry_depth_ratio，并确认中心区与各臂交界处没有重叠。
  • 频繁出现 Unknown：通常是区域之间存在空隙，或质心落到了未覆盖边界。
  • 热图看起来偏位：先复核 5 区画区和真实尺寸填写是否正确。

什么时候一定要人工复核

如果结果将用于正式统计或论文结论，建议至少抽查结果视频，尤其是开放臂边缘反光明显、总入臂数过低或区域切换异常频繁的视频。

Complete Elevated Plus Maze Manual

This manual covers assay logic, recording requirements, five-zone drawing, detection masks, time windows, key parameters, and EPM result interpretation.

5 manual zones Open / closed arm time Entry-depth gating Optional mask track / summary / bins

What is quantified

The module separately measures open-arm, closed-arm, and center occupancy, then exports ratios, latency, distance, speed, and arm-entry metrics.

Why all five zones are manual

Each ROI explicitly defines center, open arm 1/2, and closed arm 1/2, which avoids boundary drift from auto-derived geometry.

Why entry depth matters

An arm entry is counted only after the centroid moves deeper into the arm, reducing repeated counting near the center junction.

1Overview

The EPM module quantifies preference across open arms, closed arms, and the center. Accurate zone drawing and preview-based confirmation of arm-entry logic are the most important steps.

  • Open-arm time ratio and open-entry ratio should usually be interpreted together with total arm entries and total distance.
  • The center is tracked separately instead of being merged into either arm class.
  • If a video contains multiple mazes, each ROI generates its own result tables and maps.

2Recording requirements

  • Use a stable top view or near-top view and avoid camera motion or zoom changes.
  • Keep the center and all four arms visible with minimal clipping.
  • Maintain strong contrast between the mouse and maze floor while minimizing glare and shadow.
  • If bright background outside an open arm causes false detection, prefer a detection mask.

3Upload and timing

  • Use global start and end time if you only want a specific segment of the video.
  • Override FPS if metadata is unreliable, because speed, distance, and latency depend on it.
  • Multi-video sessions open the batch page first so each video can be configured independently.

4Five-zone drawing and timing

  • Each ROI represents one full maze with center, open arm 1/2, and closed arm 1/2.
  • Each zone is defined by four corner clicks. Point order is normalized automatically.
  • Enter center size, open-arm length, and closed-arm length so MouseScope can estimate cm_per_px_est.
  • The detection mask limits where foreground detection is allowed but does not redefine the statistical zones.

6Outputs

  • *_analyzed.mp4: annotated video with hand-drawn zones, zone labels, entry events, and trajectory overlay.
  • *_track.csv: frame-level records of zone, speed, cumulative distance, and arm-entry events.
  • *_summary.csv: one-row-per-ROI summary table with the main EPM metrics.
  • *_bins.csv: fixed-width temporal bins for time allocation, entries, and distance.

7Batch workflow

  1. Upload multiple EPM videos and define global timing, FPS override, and output folder.
  2. Open each video card and finish five-zone drawing, masks, timing, and tuning for that video.
  3. Save the current setup and return to the batch page before moving to the next video.
  4. Only start analysis after all cards are marked complete.

8Troubleshooting

  • Open-arm time unexpectedly high: check whether the open arms are too wide or whether bright background leaked into detection.
  • Open-arm time unexpectedly low: check whether the open arms are too narrow or arm-edge shadows are breaking the contour.
  • Entry counts too high: increase entry_depth_ratio and confirm that center-arm boundaries do not overlap.
  • Frequent Unknown states usually indicate gaps between zones or uncovered boundary areas.
